TF-DEV-031 Wird die Knopfbeschriftung des Entwicklertischs bei Stelle, Karten-Id oder Spieler verfälscht, werden die Beschriftungstests rot.

Bereich Entwicklertisch unter /dev (nur Testhook-Build)Regression neinPriorität mittelArt manuell

Worum es geht

Die Tests zu beschriftung.ts sind nach dem Code entstanden. Ob sie Fehler fangen, zeigt erst eine Gegenprobe: je eine Zeile verfälschen, Tests ausführen, zurücksetzen.
