TF-PRUEF-030 Entfernt man eine Regel aus der KI-Grenze des Architekturtests, wird mindestens ein Test rot.

Bereich Prüfwerkzeuge: Regelcheck, Architekturtest, Geräteklassen, Bildschirmfotos, Anleitungen für die AbnahmeRegression neinPriorität mittelArt manuellGrenzfall von TF-PRUEF-028

Worum es geht

Jede Regel der KI-Grenze (Prüfung in tests/architektur_ki_pruefung.ts, Listen in tests/architektur_ki_listen.ts) soll durch einen eigenen Test belegt sein. Sonst kann sie bei einer späteren Vereinfachung verschwinden, ohne dass es jemand merkt. Geprüft wird an zwei Regeln: der Liste der freigegebenen Engine-Funktionen und dem Verbot geerbter Methoden wie valueOf an globalen Objekten.

Bestanden, wenn

Nimmt man serialisiere in ERLAUBTE_ENGINE_EMPFAENGER auf, wird „H2: serialisiere aus der Engine“ rot. Streicht man valueOf aus GEERBT_VON_OBJECT, wird ebenfalls mindestens ein Test in tests/architektur_ki.test.ts rot.

Fehlgeschlagen, wenn

Nach einer der beiden Änderungen enden npx vitest run tests/architektur.test.ts tests/architektur_ki.test.ts ohne roten Test.
