TF-SPEC-019 Wird in D34–D55 eine vorgeschlagene Möglichkeit durch eine andere ersetzt oder ein Satz einer Teilantwort gestrichen, schlagen die P0.5-Tests fehl.

Bereich Regelspiegel, Regelfragen an den Autor und Website-AbgleichRegression neinPriorität hochArt manuellGrenzfall von TF-SPEC-018

Worum es geht

Die Tests zu D34–D55 sollen den Inhalt jeder Teilantwort festhalten, nicht nur, dass ein Eintrag da ist. Sonst kehrt eine spätere Änderung eine Regel der Erweiterung unbemerkt um, etwa eine zweite Farbenfusion im Korb-Zug.
