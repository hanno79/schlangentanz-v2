TF-DEV-005 Ungültige Adressen unter /dev zeigen eine rote Meldung mit Grund statt einer anderen Partie.

Bereich Entwicklertisch unter /dev (nur Testhook-Build)Regression neinPriorität mittelArt manuellGrenzfall von TF-DEV-001

Worum es geht

Wird eine falsche Saat still ersetzt, glaubt ein Prüfer, er sehe die verlangte Partie. Geprüft werden Werte genau auf und neben den Grenzen.

Bestanden, wenn

seed=0 und seed=4294967295 (mit 2 bzw. 3 Spielern) zeigen eine Partie. Jede der folgenden Adressen zeigt eine rote Meldung mit Grund und keine Partie: seed=4294967296, seed=-1, seed=abc, seed=1.5, spieler=1, spieler=5, spieler=2.0, fehlendes spieler, fehlendes seed, erweiterung=2, szenario=gibtsnicht, szenario=, szenario=spielende&seed=1, Pfad /dev/xyz. /devx zeigt seit O2 die Seite für unbekannte Adressen „Diese Seite gibt es nicht“.

Fehlgeschlagen, wenn

Eine der ungültigen Adressen zeigt eine Partie, eine leere Seite oder einen Konsolenfehler.
