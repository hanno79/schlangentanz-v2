TF-DEV-003 Im Produktionsbuild ist /dev nicht erreichbar, und kein Code des Entwicklertischs steht im Bundle.

Bereich Entwicklertisch unter /dev (nur Testhook-Build)Regression jaPriorität hochArt beides

Worum es geht

Der Entwicklertisch zeigt alle Hände offen und ist eine Test-Hintertür. In der ausgelieferten App darf er weder erreichbar sein noch im ausgelieferten JavaScript stehen (Plan P0.4, Kriterium 3).

Bestanden, wenn

npm run build erzeugt nur index-*.js, index-*.css und prod-*.js; eine Suche in dist/ nach ntwicklertisch, Festgefahren, kaputt-doppelte-karte, Phasenschritte, Invariante, szenario, /dev und 0x6d2b79f5 findet nichts. http://localhost:4173/dev?seed=1&spieler=2 zeigt seit O2 nur die Seite für unbekannte Adressen „Diese Seite gibt es nicht – Unter /dev ist nichts zu finden.“ und lädt nur index-*.js und index-*.css.

Fehlgeschlagen, wenn

Eine Datei in dist/ enthält einen der Suchbegriffe, ein Chunk Entwicklertisch-*.js entsteht, oder /dev auf Port 4173 zeigt den Tisch oder lädt einen weiteren Chunk.
