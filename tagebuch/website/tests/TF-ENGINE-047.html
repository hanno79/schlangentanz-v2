TF-ENGINE-047 Jede der sechs Verfälschungen der Schlangenhäutung macht mindestens einen Test von E9 rot.

Bereich Spiel-Engine: Regeln, Zugablauf, Wertung, SpeicherformatRegression neinPriorität mittelArt manuell

Worum es geht

Tests, die nie rot werden, belegen nichts. Hier wird die Regel in src/engine/karten/schlangenhaeutung.ts an sechs Stellen absichtlich verfälscht, und nach jeder Verfälschung müssen die Tests von E9 einen Fehler zeigen.

Bestanden, wenn

Nach jeder Verfälschung endet der Lauf über A7.9_schlangenhaeutung.test.ts, A7.9_schlangenhaeutung_abwehr.test.ts und szenarienHaeutung.test.ts mit Exit 1. Erwartete Zahl roter Tests von 35: GP1 9, GP2 9, GP3 2, GP4 3, GP5 9, GP6 12. Nach dem Zurücksetzen ist git status leer.

Fehlgeschlagen, wenn

Eine Verfälschung lässt alle 35 Tests grün, oder die Datei ist nach dem Zurücksetzen noch geändert.
