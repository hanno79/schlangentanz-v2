# Satz für Satz: A7.10, A8 und A9 (X7)

Diese Tabelle führt jeden Satz der Abschnitte A7.10 (Schlangenkorb des Glücks),
A8 mit A8.1 (Comeback-Karte) und A8.2 (Risiko-Belohnungs-Karte) und A9
(Aufgabenkarten) aus Teil A von `docs/GAME_SPEC.md` wörtlich auf und nennt die
Regeltests, die ihn belegen, als `Datei › Testname` (Datei unter
`src/engine/__tests__/regeln/` ohne `.test.ts`). Ein Name mit `%s`, `%i` oder
`$…` ist ein Test mit mehreren Fällen; ein Name ohne solche Platzhalter, der
kein Test ist, ist eine Zeile einer Entscheidungstabelle in dieser Datei. Sätze
ohne eigene Regel, etwa Zwischenüberschriften, stehen in der zweiten Tabelle mit
Grund.

Zerlegt wird wie in `src/engine/__tests__/regeln_abdeckung.test.ts`: je Zeile
ohne Überschrift, Spiegelstrich und Fettdruck, an Satzenden getrennt, aus der
Aufgabentabelle in A9 die Bedingung; derselbe Satz zählt je Abschnitt einmal.
Der Meta-Test verlangt, dass jeder so gefundene Satz genau einmal hier steht und
dass jeder genannte Test in seiner Datei existiert. Die Auslegungen aus Teil D
(D34 bis D79) belegen die Prüfprotokolle von X1 bis X6 unter `docs/abnahme/`.
