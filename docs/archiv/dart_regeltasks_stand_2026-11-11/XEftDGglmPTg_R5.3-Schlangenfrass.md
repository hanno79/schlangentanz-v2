## Sonderkarte: Schlangenfrass

Anzahl im Deck: 4 Stück

---

## Effekt

Entfernt Karten vom Ende einer gegnerischen Schlange.

---

## Durchführung Schritt für Schritt

1. Der Spieler spielt die Schlangenfrass-Karte aus seiner Hand
2. Der Spieler wählt einen Gegner aus
3. Der Spieler wählt eine Schlange des Gegners aus
4. Der Spieler wählt ein Ende der Schlange (Kopf oder Schwanz)
5. Die letzten 1-3 Karten (Spieler wählt Anzahl) werden vom gewählten Ende entfernt
6. Entfernte Karten kommen auf den Ablagestapel
7. Die Schlangenfrass-Karte kommt auf den Ablagestapel

---

## Einschränkungen

- Kann NICHT auf eigene Schlangen angewendet werden
- Kann NICHT auf geschützte Farbgruppen angewendet werden (Farbenschutz)
- Eine Schlange kann auf 0 Karten reduziert werden (Schlange verschwindet)
- Maximum 3 Karten pro Schlangenfrass entfernen

---

## Use Cases

- UC-R5.3-A: Angriff auf Gruppe - Gegner hat Rot-Rot-Rot am Ende, alle 3 werden entfernt
- UC-R5.3-B: Teilentfernung - Nur 2 von 5 Karten entfernen
- UC-R5.3-C: Schlange zerstören - 3-Karten-Schlange wird komplett entfernt
- UC-R5.3-D: Schutz aktiv - Angriff wird durch Farbenschutz blockiert
- UC-R5.3-E: Kopf oder Schwanz - Spieler wählt strategisch das Ende

---

## Akzeptanzkriterien

- Schlangenfrass kann nur auf gegnerische Schlangen gespielt werden
- 1-3 Karten können entfernt werden (Spieler wählt)
- Farbenschutz blockiert den Angriff auf geschützte Bereiche
- Entfernte Karten gehen auf den Ablagestapel
- Leere Schlangen verschwinden automatisch
